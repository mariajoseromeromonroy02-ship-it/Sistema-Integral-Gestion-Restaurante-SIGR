# Frontend SIGR

Este módulo contiene la interfaz gráfica del Sistema Integral de Gestión de Restaurante.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Funcionalidades

- Login
- Gestión de pedidos
- Reservas
- Reportes
- Facturación

## Objetivo

Permitir la interacción de los usuarios con el sistema mediante interfaces modernas y responsivas.
