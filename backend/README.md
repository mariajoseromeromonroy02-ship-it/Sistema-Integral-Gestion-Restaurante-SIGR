# Backend SIGR

Este módulo contiene la lógica de negocio del Sistema Integral de Gestión de Restaurante (SIGR).

## Tecnologías utilizadas

- Node.js
- Express.js
- MySQL

## Componentes

- Controladores
- Rutas
- Modelos
- Middleware
- Configuración

## Objetivo

Gestionar la comunicación entre la interfaz gráfica y la base de datos.
